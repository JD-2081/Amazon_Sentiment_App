# 📦 Amazon Review Sentiment Analysis

This project analyzes Amazon product reviews and predicts whether a review is **positive or negative** using Machine Learning and Deep Learning techniques.

---

## 🚀 Project Overview
Online stores receive thousands of customer reviews.  
This system automatically classifies reviews into positive or negative sentiments using NLP and an LSTM neural network model.

---

## 🎯 Project Objective
To build a system that:
- Reads customer reviews
- Understands sentiment
- Predicts review polarity automatically

---

## 🛠 Technologies Used
- Python
- Pandas & NumPy
- TensorFlow / Keras
- Scikit-learn
- Matplotlib & Seaborn
- Streamlit (for deployment)
